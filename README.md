## Event Builder

A simple interactive event page built with HTML, CSS, and vanilla JavaScript.

### Features

- Event details and program display.
- Optional service selection with price calculation.
- JSON parsing and error handling.
- Report generation using `filter()`, `map()`, and `reduce()`.
- JSON report serialization and validation.

### Requirements

- Modern web browser.

### Run

Open `index.html` in a web browser.

No server or external dependencies required.
